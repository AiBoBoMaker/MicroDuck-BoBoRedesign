# BoBoMaker MicroDuck HD1910 固件许可说明

> **简体中文** | [English](BOBO-LICENSE.en.md)

## 项目来源

本目录下的固件代码基于以下项目开发：

- **[Pollen Robotics Microduck](https://github.com/pollen-robotics/microduck)** — 官方 Microduck 0.15.1 版本，采用 [Apache-2.0 License](LICENSE)
- **[kissqy/Microduck-kissqy](https://github.com/kissqy/Microduck-kissqy)** — kissqy 的飞特舵机版本适配

感谢官方团队和 kissqy 的开源贡献，本项目在此基础上进行了适配和修改，以支持飞特 HD-1910 舵机。

## 用途说明

本固件用于 MicroDuck 鸭子机器人的调试、标定和运行，支持通过以下方式访问：

- **安卓手机 / 平板** — 通过 Web 控制台连接机器人进行调试和控制
- **电脑浏览器** — 访问机器人 Web 界面进行标定、参数调整和运行监控
- **手柄控制** — 通过蓝牙手柄进行实时操控
