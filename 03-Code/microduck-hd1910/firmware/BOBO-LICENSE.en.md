The firmware code in this directory is developed based on the following projects:

- **[Pollen Robotics Microduck](https://github.com/pollen-robotics/microduck)** — Official Microduck 0.15.1, licensed under [Apache-2.0 License](LICENSE)
- **[kissqy/Microduck-kissqy](https://github.com/kissqy/Microduck-kissqy)** — kissqy's Feetech servo adaptation

Thanks to the official team and kissqy for their open-source contributions. This project has been adapted and modified to support the Feetech HD-1910 servo.

## Purpose

This firmware is used for debugging, calibration, and operation of the MicroDuck robot, accessible via:

- **Android phone / tablet** — Connect to the robot via Web console for debugging and control
- **Desktop browser** — Access the robot's Web interface for calibration, parameter adjustment, and runtime monitoring
- **Gamepad control** — Real-time control via Bluetooth gamepad
