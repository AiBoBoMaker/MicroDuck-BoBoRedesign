# HD-1910-C001 飞特舵机版 3D 打印外壳

> 基于飞特 HD-1910-C001 舵机的 MicroDuck 外壳 3D 打印模型

## 概述

本目录包含 MicroDuck BoBoRedesign 项目的 **飞特舵机版 3D 打印外壳** 模型文件，适配 **飞特 HD-1910-C001** 舵机。

> **版本说明：** 当前版本移植自 [kissqy/Microduck-kissqy](https://github.com/kissqy/Microduck-kissqy) 项目，感谢 kissqy 的模型设计支持。本项目将基于此版本继续改进。

## 当前状态

- **版本已确认可行** — 经过实际打印和装配验证，结构和装配均无问题
- **摆盘已优化** — 模型已重新整理摆盘，按打印颜色和材质分类，方便直接打印
- **可放心打板** — 欢迎大家放心打印尝试

## 文件结构

```
02-HD-1910-C001/
├── stl模型/          # 最新模型（按颜色/材质分类）
│   ├── TPU部分/      # 柔性材料零件（TPU 打印）
│   ├── 支撑部分/     # 结构支撑件
│   ├── 橙色部分/     # 橙色外壳件
│   ├── 躯体部分/     # 主体躯壳件
│   └── 黑色部分/     # 黑色结构件
└── 老版/             # 早期版本模型（仅供参考）
```

### 模型分类

| 分类 | 说明 | 包含零件 |
|------|------|----------|
| `TPU部分/` | 柔性材料零件（TPU 打印） | 左脚底、右脚底、滑轮 |
| `支撑部分/` | 结构支撑件 | 左/右胯侧摆、左/右膝支撑、头部旋转、脸、左/右颈部固定 |
| `橙色部分/` | 橙色外壳件 | 左/右脚、左/右脚掌、嘴巴、头部集成板、左/右滑轮支架、眼睛 |
| `躯体部分/` | 主体躯壳件 | 左/右壳、左/右胯外壳、头盖、电池仓（M2.5螺丝/HUB组合）、电池仓（卡扣加厚） |
| `黑色部分/` | 黑色结构件 | 左/右胯固定片、左/右胯旋转、左/右腿固定片、头部侧倾、头部集成盖、躯干台 |

> **注意：** 老版模型保留在 `老版/` 目录中供参考，新版模型请使用 `stl模型/` 目录中的文件。

## 打印建议

- **外壳件（橙色/黑色/躯体/支撑）：** 推荐使用 PLA 或 PETG，层高 0.2mm，填充 20% 以上
- **TPU 件（脚底/滑轮）：** 推荐使用 TPU 85A-95A 硬度，层高 0.2mm，填充 15%-20%
- **支撑：** 根据模型结构酌情开启，建议树状支撑以减少表面痕迹
