# R18 安装

这一包是 R18。它把固件目录里安装所需的文件打成 `Microduck-R18.zip`。解压后，包根的 `install-R18.sh` 会调用 `scripts/install-local.sh`。

程序装到 `/opt/robot/daemon/current/bin`，配置写到 `/etc/robot/robotd.toml`。这是干净板子上的安装，不走 R17 中控里的「升级所选固件」。

## 在电脑上打包

需要 `cargo-zigbuild`、Zig 和 Rust 才能重新编译。在 `firmware` 目录执行：

```bash
bash pack-R18.sh
```

Windows 上执行：

```bat
pack-R18.bat
```

成功后，同目录出现 `Microduck-R18.zip`。脚本会交叉编译 `robotd`；本机没有这套工具时，只把已有的 `target/aarch64-unknown-linux-gnu/release/` 程序打进去。包里没有 `robotd` 时，鸭子上的服务文件仍会装上，但不会开机自启。

## 在鸭子上安装

把 `Microduck-R18.zip` 拷到鸭子上，解压，进入解压出来的目录：

```sh
sudo sh install-R18.sh
```

按提示选择板子、舵机串口、IMU 和配网键。鸭子上要有正在运行的 systemd 和 `python3`。改过设备树时，脚本会提示再执行 `sudo reboot`。
