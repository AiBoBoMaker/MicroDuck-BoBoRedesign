# R18 安装

这一包是 R18。它把固件目录里安装所需的文件打成 `Microduck-R18.zip`。解压后，包根的 `install-R18.sh` 会调用 `scripts/install-local.sh`。

程序装到 `/opt/robot/daemon/current/bin`，配置写到 `/etc/robot/robotd.toml`。这个目录里是一整套程序，不是只有 `robotd`：

`robotd`、`configd`、`btd`、`mediad`、`padd`、`tofd`、`updaterd`、`robotctl`、`sounds`、`pet-detect`、`pet-features`

另装 **GameSir 输入桥** `gamesir-xboxd`（`padd` 只认虚拟 Xbox，不读原始 `GameSir-Nova 2 Lite` 节点），并把 `robotctl` 链到 `/usr/local/bin`。Radxa / Orange Pi 会写 `/var/lib/robot/weird-ble`，让 `robotctl pad pair` 配对时暂停 `btd`（aic8800）。

`btd`、`mediad`、`padd`、`tofd` 用各自的系统账号启动，安装脚本会通过 `systemd-sysusers` 建好。这是干净板子上的安装，不走 R17 中控里的「升级所选固件」，也不安装 `/opt/robot/feetech-ft5-r5/service.sh`。

## 在电脑上打包

需要 `cargo-zigbuild`、Zig 0.15.1 和 Rust。Windows 上的 `pack-R18.bat` 进入本机 WSL 编译；第一次会在 WSL 里装上这些工具。Rust 1.99.0 走腾讯云镜像，crates.io 和 Debian sysroot 走清华源。国内镜像没有 Zig 0.15.1 这份预编译包，脚本从 zig.linus.dev 下载。在 `firmware` 目录执行：

```bash
bash pack-R18.sh
```

Windows 上执行：

```bat
pack-R18.bat
```

成功后，同目录出现 `Microduck-R18.zip`。脚本在 WSL 里准备 aarch64 sysroot，再交叉编译上面列出的全部程序。缺任何一个程序时打包停下来，不再打出只有 `robotd` 的包。`mediad` 和 `padd` 要链接板上的 GStreamer 和 libudev。

## 在鸭子上安装

**拷到 TF 卡 / 解压 / 选板型 / 自检**：见同目录 [`R18-TF卡安装.md`](R18-TF卡安装.md)（逐步说明）。

把 `Microduck-R18.zip` 拷到鸭子上（推荐 `/home/orangepi/`），解压到 `/opt/microduck-r18`，进入解压目录：

```sh
sudo sh install-R18.sh
```

按提示选择板子、舵机串口、IMU 和配网键。鸭子上要有正在运行的 systemd 和 `python3`。改过设备树时，脚本会提示再执行 `sudo reboot`。

安装脚本还会装 **ONNX Runtime 1.28.0**（`libonnxruntime.so` → `/usr/local/lib`，并给 `robotd` 写 `ORT_DYLIB_PATH`）。缺它时策略校验失败会静默关掉走路。优先用包内/板上已有的 tarball；没有则从 GitHub 下载。国内若下不动，在电脑上下好后拷到鸭子：

```text
/tmp/onnxruntime-linux-aarch64-1.28.0.tgz
```

或放到解压目录的 `vendor/` 下再跑安装。

HD1910 的 `policy.onnx` **不在** R18 zip 里。从 R17 固件包或旧机拷到：

```text
/opt/robot/feetech-ft5-r5/models/<模型ID>/
```

若安装时已发现这些文件，脚本会询问是否把 `/etc/robot/robotd.toml` 的 `[policy]` 指过去（对照 `config/robotd-selftrained.toml`）。

### 板型选项

| 编号 | 板子 | 默认舵机口 | 设备树 |
| --- | --- | --- | --- |
| 1 | Radxa ZERO 3W | `/dev/ttyS2` | `uart2-m0` + aic3104 I2C overlay |
| 2 | Orange Pi Zero 2W | `/dev/ttyS0`（排针 8/10） | 见下 |
| 3 | 通用 Ubuntu | 自填 | 不改 |

### Orange Pi Zero 2W（安装脚本会做的事）

舵机总线是 **UART0 = `/dev/ttyS0`**（排针 8 TX、10 RX）。飞特要 **1 Mbps**。脚本会：

1. **腾出 UART0**：屏蔽 `serial-getty@ttyS0`；`/boot/orangepiEnv.txt` 设 `console=display`；改 `/boot/boot.cmd` 的 display 分支，去掉内核参数里的 `console=ttyS0,115200`，再 `mkimage` 写 `boot.scr`。Type-C 上的 `ttyGS0` 控制台保留。不要加载 `sun50i-h616-disable-uart0`。
2. **改波特率底座**：安装 `apb2-300m` user overlay，把 APB2 提到 300 MHz，使 `Baud_base ≈ 18.75 M`，1 Mbps 分频可用。
3. **HAT 音频**：安装 `aic3104-h616`（ahub0 + TLV320@0x18，`mclk-fs=256`），并启用 `aic3104-init.service` 打开 Line Out / AHUB 路由。`robotd` 用 `plughw:aic3104`。

重启后自检：

```sh
cat /proc/cmdline                    # 不应再有 ttyS0
setserial -ag /dev/ttyS0             # Baud_base 约 18750000
aplay -l | grep aic3104
```

## 实体手柄（盖世小鸡 Nova 2 Lite）

安装完成后配对（手柄：**Home+X** 进 PC 模式，再 **Home+截图键** 到**快闪**）：

```sh
sudo robotctl pad pair
sudo robotctl pad status
```

期望 `connected`，且：

```sh
systemctl is-active gamesir-xboxd.service padd.service
sudo gamesir-xbox-status
```

桥应报告 physical GameSir + virtual Xbox 都 present。不要用中控 R17「随包固件」整包覆盖 R18；缺桥时重跑本包的 `install-R18.sh` 即可。

## 中控（BoBoMaker）与语音对话

页面标题是 **BoBoMaker · Microduck 控制台**，主要是调试/运行。BoBo 语音对话由**手柄 R3 / 菜单键**触发（实体 `padd` 或网页模拟手柄 → `robot.voice`），不是顶栏「聊天」页。

| 控件 | 作用 |
| --- | --- |
| **连接**（SSH 表单） | 连上鸭子的 SSH，拉起 robotd 数据 |
| **调试** | 切到 commissioning：关节标定 / IMU 确认 |
| **运行** | 切到 motion：写 `motion_enabled=true` 后进运动循环 |
| **停止并松开** | 卸力 / relax |
| **Start**（模拟手柄） | 首次 HOME；之后开/关策略 |
| **LT / RT** | 长叫 / 短叫（预设鸭叫） |
| **R3（右摇杆按下）或 Guide/菜单键** | **接通 / 打断 / 挂断 BoBo 语音对话** |
| **连接摄像头** | 头部 WebRTC 画面 |

### 打开 BoBo 语音对话

在 `/etc/robot/robotd.toml` 配置（见 `deploy/robotd.toml` 的 `[bobo]`）：

```toml
[bobo]
enabled = true
url = "http://music.ota.bobomaker.com/xiaozhi/ota/"   # OTA（推荐）；或直接 ws(s)://
# token = ""
# client_id_path = "/var/lib/robot/bobo-client-id"
```

`url` 填 **OTA 的 http(s)** 时，接通前会先向 OTA 登记并拿到 websocket（与 py-xiaozhi 相同）；也可直接填 `ws://` / `wss://`。接通成功后会快速 **滴滴两声**，再开始听；停说/识别由云端 VAD 完成。

并保证 `[audio] enabled`。需要麦克风；通话期间建议关掉会抢麦的 `pet_detect`。

实体手柄：按 **R3** 或 **Guide（Xbox 中央键 / 菜单键）** — 接通并听；对方说话时再按可打断；听筒空闲时再按挂断。网页模拟手柄：**R3 · 对话** 或中央 **菜单键（✥）** 走同一条 `robot.voice`。

`robotd` 日志里会看到：`语音对话待命：右摇杆按下或菜单键接通`。

### 语音关键词动作

中控 **BoBo 语音** 面板可配置：左侧关键词、右侧预设头动（摇头晃脑 / 点头 / 使劲摇头 / 哈哈大笑）或机器上已部署的模型动作。保存后写入鸭子 `/var/lib/robot/bobo-keywords.json`，约 2 秒热加载，无需重启。

通话中 ASR 返回的文字若包含关键词，且鸭子正**坐着或站着空闲**（未执行其他模型动作、未在行走），则触发对应动作；忙时忽略。也可在 toml 里写：

```toml
[[bobo.keyword]]
match = "点头"
action = "preset:nod"
```

清卡再配网等踩坑见 [`R18-TF卡安装.md`](R18-TF卡安装.md) §7。
